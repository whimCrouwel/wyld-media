# 並列開発プロトコル

複数のターミナル(= 複数の Claude エージェント)が**同じ作業ツリー・同じブランチ**で同時に作業するためのルール。worktree は使わない前提なので、分離ではなく**調整**で衝突を防ぐ。

宣言板は [`AGENTS-ACTIVE.local.md`](../AGENTS-ACTIVE.local.md)(リポルート、`*.local.md` パターンで gitignore 済み)。

## 開始時

1. `AGENTS-ACTIVE.local.md` を読む(なければテンプレートごと作る)。
2. 他エージェントの「触るパス」と自分の作業が重なるなら、**着手せずユーザーに報告**して調整する。
3. 重ならなければ自分のブロックを追記して着手:

```markdown
## <エージェント名や作業スラッグ> (YYYY-MM-DD HH:MM 開始)
- 作業内容: 一行で
- 触るパス:
  - admin/src/lib/xxx.ts
  - admin/tests/xxx.test.ts
```

- 作業スコープが広がったら、触る前にブロックを更新する。
- タイムスタンプが 6 時間以上前のブロックは stale とみなして無視してよい(消してよい)。

## Git ルール(最重要)

全員が同じ作業ツリー・同じブランチを共有している。相手の**未コミットの変更**が常にツリー上にあると思って操作すること。

- **`git checkout` / `git switch` / ブランチ切替は禁止。** 相手の見ているファイルがすり替わる。ブランチを変えたい場合は全エージェント終了をユーザーに確認してから。
- **`git add -A` / `git add .` / `git commit -a` は禁止。** 相手の書きかけを巻き込む。**必ず自分の宣言パスを個別に `git add`** してからコミットする。
- **`git stash` / `git reset --hard` / `git pull --rebase` / `git rebase` は禁止。** 相手の未コミット変更を破壊する。pull が必要なら `git pull --ff-only` のみ。
- `git status` に自分の触っていないファイルの変更が見えるのは正常(相手の作業中ファイル)。消そうとしない。

## 共有リソースのルール

- **ローカル Supabase は1つを全員で共有。** 他エージェント活動中は `supabase db reset`・`supabase migration new`・`npm run seed` を**実行しない**。必要ならユーザーにハンドオフを依頼する。
- **`supabase/migrations/`・`package.json`・`package-lock.json`・`astro.config.mjs`・設定ファイル類は単独占有。** 触りたければ先に宣言板でパスを宣言し、他エージェントの宣言と重なっていないことを確認する。
- **`npm install` も占有操作。** node_modules と lock ファイルは共有なので、並行実行は禁止。
- **開発サーバー(`npm run dev:all` = :4321/:4322/Edge Functions)は先着1エージェントのみ。** 後続は起動を試みず、既に立っているサーバーを閲覧・確認に相乗りする(コード変更はライブリロードで反映される)。
- **`docs/TODO.md` は追記前に必ず読み直す。** 両エージェントが頻繁に追記するファイルなので、古い内容を前提に編集しない。

## 同一ファイルの編集衝突が起きたら

Edit ツールは「読んだ後に外部変更されたファイル」への編集を拒否する。このエラーが出たら相手が同じファイルを触ったサイン — ファイルを**読み直してから**編集をやり直す。頻発するなら作業が重なっているので、宣言板を見直してユーザーに報告する。

## 終了時

1. 自分の宣言ブロックを `AGENTS-ACTIVE.local.md` から削除する。
2. コミットは自分の宣言パスのみ(上記 Git ルール)。
